
mrintegrate

mrintegrate is an R package developed as part of the RE-INTEGRATE
project.

The package provides a framework for reading, cleaning, transforming,
and organizing input data from a variety of external datasets, making
them ready for further analysis and modelling workflows.

If you have any questions or encounter any issues, please feel free to
contact the package developers.

Installation

Install the development version directly from GitHub:

devtools::install_github(“e3modelling/mrintegrate”)
